# 可視化

[English](visualization.md) | [日本語](visualization.ja.md)

`brinsfield-tools` Python パッケージが ABM 出力を描画する．

どの run を読むかは `runvault path --latest` が答えるので `--results-dir` は省略できる．
特定の run を指したいとき（runvault 移行前の legacy な `results/<timestamp>/` を含む）
だけ渡す．図は run の外
（`<results-root>/brinsfield-silence/figures/<run_slug>/`）に出す — `manifest.csv` は
`finish()` が確定させるので，run が終わった後に作ったものを中に置くとハッシュを持たない
ファイルが記録に混ざる．

## `visualize`（単一 run）

```bash
uv run brinsfield-tools visualize
uv run brinsfield-tools visualize --results-dir results/20260529_143329   # legacy も可
```

- `motive_mix_stack.png` — primary 動機比率の 6 領域積上げ面グラフ（時系列）．
- `silence_kl_timeseries.png` — step 別の沈黙率と `KL(mix‖reference)`．
- `motive_correlate_bar.png` — 最終 step の各動機と ψ（defensive/diffident/relational で負）・神経症（deviant/diffident で正）との Pearson r．

## `visualize-sweep`

```bash
uv run brinsfield-tools visualize-sweep
```

`sweep_summary.csv` はもうディスクに無い．掃引親の子 run から
`brinsfield_tools.runs.sweep_summary_table` が同じ列の表を組み直す．

- `sweep_defensive_heatmap.png` — ψ_learn × p_retaliate 上の defensive 比率．
- `sweep_kl_contour.png` — motive-init-defensive × p_retaliate 上の `KL(mix‖reference)` 等高線．
- `sweep_motive_response.png` — 初期 defensive 比率に対する定常動機比率（12.65% アンカー線付き）．

## `show-experiment-settings`

```bash
uv run brinsfield-tools show-experiment-settings
uv run brinsfield-tools show-experiment-settings --subcommand sweep
```

run の `config.json` にある条件と，LLM モードの run にかぎり LLM の素性を表示する —
provider / model / 温度は `run.json` の `llm` ブロック，呼び出し数と cache-hit は run
スコープの `llm_*` 指標が正本である．rule モードの run には `llm` ブロックが無いので，
`none` というモデルを名乗る行はもう出ない．`--json` で機械可読出力．
