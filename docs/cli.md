# CLI reference

[English](cli.md) | [日本語](cli.ja.md)

The `brinsfield` binary has four subcommands.

Where the output goes and how a run is identified belong to
[runvault](https://github.com/akitenkrad/rs-runvault). Every subcommand creates run
directories under `<--output-dir>/brinsfield-silence/`; there is no timestamped
directory of our own and no `results/latest` symlink. Resolve a run with
`runvault path --experiment brinsfield-silence --latest --subcommand <name>`.

## `run`

Single configuration. Creates one run holding `config.json` (the conditions),
`metrics.csv` (the per-step metrics plus the run-scope ones), `events.jsonl`
(one `x.brinsfield2013.agent` row per employee), `reference.csv` (the paper's
12.65% defensive share) and `manifest.csv`.

`--runs N` is not a sweep: it repeats the same condition N times and keeps only the
last one, as it always has. The run therefore records `master_seed =
derive_seed(seed, [N-1])` with `replicate_index = N-1`; the root seed is in
`parameters.base_seed`.

| Flag | Default | Meaning |
|------|---------|---------|
| `--decision-mode` | `rule_6dim` | `llm` / `rule_6dim` / `rule_4dim` / `rule_3dim` |
| `--n-teams` / `--team-size` | 5 / 8 | organisation shape |
| `--n-levels` | 3 | hierarchical levels (descriptive) |
| `--network` | `watts-strogatz` | `watts-strogatz` / `erdos-renyi` / `barabasi-albert` |
| `--network-k` / `--network-beta` | 6 / 0.1 | WS degree `k` / rewire β (or ER `p`) |
| `--supervisor-homogeneity` | 0.0 | η_sup ∈ [0,1] toward a common supervisor openness |
| `--motive-init` | `0.35,0.20,0.13,0.13,0.13,0.06` | initial six-motive distribution |
| `--motive-learn-rate` | 0.10 | EMA η for `motive_dynamics` |
| `--psafety-learn` | 0.05 | ψ learning rate |
| `--p-retaliate` | 0.05 | per-agent per-step retaliation probability |
| `--shock-t` / `--shock-magnitude` | none / 0.3 | exogenous σ shock |
| `--temperature` / `--prompt-version` | 0.0 / 1 | LLM temperature / prompt template v1–v3 |
| `--t-max` / `--runs` / `--seed` | 48 / 1 / 42 | horizon / repeats / core seed |
| `--llm-seed` / `--llm-cache-path` | 0 / `.llm_cache/cache.json` | LLM seed offset / cache path |
| `--output-dir` | `results` | runvault results root |

## `sweep`

Cartesian product over `--psafety-learn × --p-retaliate × --motive-init-defensive`
(comma lists) × `--runs` seeds. One parent run (`--subcommand sweep`) declares the
grid; one child run per cell (`--subcommand sweep-point`) holds that cell's trials as
`observation` + `terminal` rows in `events.jsonl`, plus the cell means as run-scope
metrics. A sweep looks only at each trial's final step, so a trial has no time series
of its own and one `terminal` row says all of it.

`brinsfield_tools.runs.sweep_summary_table` rebuilds the old `sweep_summary.csv`
columns from those children.

## `ablate`

Run `--decision-modes rule_6dim,rule_4dim,rule_3dim` (comma list) side-by-side for
`--runs` each; prints per-mode mean `KL(mix‖reference)` and defensive share. Recorded
like `sweep`: a parent run (`--subcommand ablate`) plus one child per decision mode
(`--subcommand ablate-point`), whose trials are `terminal` rows.
`brinsfield_tools.runs.ablation_summary_table` rebuilds the old
`ablation_summary.csv` columns.

## `reproduce`

Runs one configuration and prints the steady-state motive_mix (mean over
`t ≥ t_max/2`) against the Brinsfield reference, with PASS/off-anchor verdicts for the
defensive 12.65% anchor, the ineffectual floor, and the deviant ceiling. The
steady-state means are recorded as the run-scope metrics
`steady_state_motive_mix_<motive>`; the tolerance bands and the verdicts are not — they
are neither the paper's numbers nor an observation, so they stay on the console.

## `mock_smoke` (example)

`cargo run --example mock_smoke -- <results-root>` drives the LLM path end-to-end with
a scripted client and no external call, recording a run with `--subcommand mock-smoke`.
It is how the LLM path is checked without a live model.
